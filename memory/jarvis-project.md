**JARVIS** is the user's project in `C:\Users\oliad\Desktop\visionpro\` (as of 2026-08-16: docs only, no code). A webcam-based spatial computing platform: any webcam becomes a gesture-controlled 3D interface (the "webcam version of Apple Vision Pro"). Hand gestures (pinch/grab/point/open/swipe) navigate a Three.js 3D space with floating windows running apps (LLM chat, web search, notes, dashboard), plus multi-user sync via WebSocket.

Three source-of-truth docs in the workspace root (created 2026-08-16):
- `PROJECT_VISION.md` — vision, features, 5-phase roadmap, success metrics
- `TECHNICAL_SPEC.md` — architecture, component interfaces (CameraCapture, HandTracker, GestureRecognizer, InteractionEngine, Scene3D, WindowManager, backend WebSocket/StateManager/APIRouter), testing strategy
- `IMPLEMENTATION_GUIDE.md` — step-by-step build guide with code (Week 1: scaffold + Three.js + camera + MediaPipe; Week 2: gestures; Week 3: floating windows; Week 4: polish; Phase 2+: apps/backend/multi-user)

Stack (decided in the docs): Vite + React + TypeScript + Three.js frontend, MediaPipe Hands (not custom ML), Node.js + Express + ws backend, Redis + PostgreSQL, Docker, Vercel/EC2 deploy. Key targets: <100ms hand-detection latency, 95%+ gesture accuracy, 60fps rendering, <200ms WebSocket RTT, 100+ concurrent users.

Build approach: the user drives via the chat (DeepSeek Flash overseer) → Orchestrator team loop (see [[zcode-agent-team]]).
